# Contributing

Jana is open source under the [Apache License 2.0](LICENSE). You are welcome to use it, study it and fork it under
those terms.

We do not accept outside code contributions or pull requests: the team cannot review and maintain them. Please do not
open pull requests.

## Security problems

Report a suspected vulnerability privately through this repository's private vulnerability reporting (the
"Report a vulnerability" button under Security), never in a public issue.

## Content

Content packs (lessons, items, diagrams and the curriculum map) are released under CC BY 4.0; each pack says so on
its attribution page. Third-party components keep their own licences; see [THIRD_PARTY_NOTICES](THIRD_PARTY_NOTICES).
