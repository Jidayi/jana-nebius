# @jana/contracts-ts

GENERATED TypeScript types and runtime validators from the specification's JSON Schemas (M1). Never edited by hand;
the codegen stage fails on any difference.

The `./client` entry provides precompiled learner-facing API/event, saved-record and visual validators with the same types and compatibility metadata as the complete entry. Both are generated by `scripts/codegen/contracts-ts.mjs`; out-of-scope contract names are refused. The complete entry remains available to authoring, services and the contract corpus. No wire schema is changed by this split.
